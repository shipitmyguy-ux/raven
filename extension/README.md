# Raven Capture

Chrome extension for sending the current page to Raven.

## Install

1. Download `raven-capture-extension.zip` from the Raven site.
2. Extract the ZIP.
3. Open `chrome://extensions`.
4. Turn on **Developer mode**.
5. Choose **Load unpacked**.
6. Select the extracted folder.

Use **Save to Raven** from Chrome's right-click menu on a job posting.
